# Prometheus
This is a personal project of mine that I have had the idea of for a while. Started in high school and on a thumb drive into a remade professional environment. This project has no expectations just a project to work on when I am bored or have motivation.

This project in a current representation of the kind of code I can make. It implements better coding practices than the previous iterations and has much more work to still be done. This project is not done and will eventually be worked on again when I have more spare time. It can run and you can fight but the enemies don't fight back and the interactive fighting animation is not completely done yet. Need to still catch up to the previous iteration's functionality but after that I have much more ideas for improving the code past the previous iteration's capabilities.

Every background photo seen in the game was generated by Prechance AI, found at https://perchance.org/ai-text-to-image-generator. I am the personal creator of the enemy sprites NOT including the final bosses.
